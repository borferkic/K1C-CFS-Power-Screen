# Fuentes de iconos Z-Bolt

Estos SVG son los cinco iconos seleccionados del directorio `styles/z-bolt/images`
del repositorio [Z-Bolt/OctoScreen](https://github.com/Z-Bolt/OctoScreen):

- `filament-spool-load.svg`
- `filament-spool-unload.svg`
- `filament-spool.svg`
- `extruder-extrude.svg`
- `extruder-retract.svg`

Los archivos `.c` de `assets/zbolt` se generan desde estas fuentes para el
formato de imágenes de LVGL.
