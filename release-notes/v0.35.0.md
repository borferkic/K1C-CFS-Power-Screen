Official release promoted from the nightly build that was tested on the K1C (same binary). It summarizes the `v0.34.x` nightlies (`v0.34.1` to `v0.34.27`).

## Highlights

- **PowerUI theme on every screen**: Home, Homing, Filament, Fine Tune, Fans, Bed Mesh, Console, Settings, System, Wi-Fi, Power Update, Calibrations, Files and Print Status. The sidebar stays on every screen, Back lives in the title bar, the Files tab replaces Console, and the colors are unified.
- **Print Status** redesigned with Pause, Cancel and Tune, a large Progress card, and an Objects button for files with labeled objects.
- **Start print dialog** with bed mesh (Off / Adaptive / Full) and adaptive purge line.
- **New tools**: Exclude Object, PID Tune, Nozzle Clean and fan temperature targets.
- **Files**: Timelapse with video previews and History with print details.
- **Calibrations**: Limits, Power Devices, Belts / Shake and Input Shaper rebuilt with shared PowerUI components and their own icons.
- **Filament**: rail buttons with small tinted icons, a Cooldown button with the nozzle icon, and a regrouped manual filament change popup.
- **Settings**: Wi-Fi, CFS, Power Update and System on the first row, the three restarts on the second, new icons, and a PowerScreen watermark with the installed version.
- **Power Update** checks for Power Script updates when it opens, has a manual check button, and is locked while printing.
- The PowerScreen Klipper macros are synced from the app at startup, with the `PS_` naming.
- **Installer**: choose the build channel, keep the boot animation and assume a clean printer.

## Fixes

- Startup crash when opening System.
- Klipper version shown in System.
- Background of the segmented selectors.
